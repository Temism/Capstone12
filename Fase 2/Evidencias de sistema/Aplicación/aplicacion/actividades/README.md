## 2. Puntos Clave de la Experiencia Infantil

1. **Ficha Técnica Mineduc Visible:** En la parte superior de cada escenario de juego, una insignia oficial muestra al docente y apoderado el **Código OA**, el **Eje temático** y el **Indicador observable (métrica)** que el estudiante está ejercitando.
2. **Audio y Efectos Procedurales Offline (`sound.js`):** La plataforma utiliza la *Web Audio API* del navegador para generar notas musicales (escalas C para conteos, sonidos de burbujas, arpegios mayores y fanfarrias) sin depender de archivos de audio externos.
3. **Mascota Asistente Robot Leo (`leo.js`):** Avatar SVG animado con soporte de lectura automática (*Web Speech API*) en español para eliminar cualquier barrera lectora en 1° básico.
4. **Sistema de Premios y Confeti (`confetti.js`):** Cada nivel superado activa una pantalla de victoria con 3 estrellas doradas y ráfagas de confeti animadas en Canvas.
