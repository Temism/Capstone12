# Reglas de Proyecto - Capstone EduConnect

## 1. Control de Versiones y Git (REGLA ESTRICTA)
- **PROHIBICIÓN ESTRICTA:** Queda terminantemente prohibido ejecutar `git commit`, `git push`, o cualquier comando que registre cambios o envíe código a repositorios de GitHub sin la autorización previa, explícita y directa del usuario.
- **Acción requerida:** Ante cualquier cambio de código, el asistente solo debe trabajar y modificar los archivos en el entorno de desarrollo local. Si se considera necesario subir cambios a GitHub, el asistente debe solicitar confirmación explícita al usuario y esperar su aprobación antes de ejecutar cualquier comando de Git (`git commit`, `git push`).

## 2. Restricciones de Estilo e Interfaz
- **CERO EMOJIS:** Prohibido el uso de emojis en archivos de código, nombres de archivos, comentarios, interfaces de usuario y mensajes de respuesta.
- **Lenguaje accesible:** En las interfaces para estudiantes (1° y 2° Básico) y apoderados, no utilizar jerga técnica.
- **Accesibilidad y Navegación:** Mantener soporte completo para interacción por teclado (barra espaciadora para avanzar, hablar y cerrar).
